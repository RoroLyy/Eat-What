# 今天吃什么 · GitHub Pages 发布版

为妈妈备菜准备的中文随机菜单网页，包含应季荤素、两套交替早餐、营养估算、菜谱、收藏及备菜清单。

## 发布步骤

1. 在你的 GitHub 账号下创建一个公开仓库。
2. 把本目录的 `index.html`、`.nojekyll` 和 `README.md` 上传到仓库 `main` 分支的根目录。不要再套一层文件夹；若网页上传界面未显示隐藏文件，可补建空的 `.nojekyll`。
3. 打开仓库 **Settings → Pages → Build and deployment**。
4. **Source** 选 **Deploy from a branch**，**Branch** 选 **main**，目录选 **/(root)**，点击 **Save**。
5. 等待 GitHub 部署完成。实际访问地址以 **Settings → Pages** 页面返回的链接为准；本包没有代替你创建仓库或完成发布。

网页无需安装依赖、构建或数据库。图片、样式及程序都包含在 `index.html` 中，不调用 Google 字体、境外 CDN、ChatGPT 登录或 chatgpt.site 域名。

## 访问与保存

GitHub Pages 的 `github.io` 域名在中国大陆可能无法访问或不稳定；本发布包不保证大陆网络可达性。请在妈妈实际使用的手机网络下检查最终链接。

菜单、收藏和清单勾选保存在当前浏览器，不在不同设备或不同域名之间同步。清除浏览器数据可能删除这些保存内容。

## 份量说明

一人份；燕麦米、大米按干重，其他食材为生重可食部。每日75克燕麦米，早餐交替安排；“低胆固醇鸡蛋”按2个蛋白估算。营养值为估算，需结合个人需求调整。图片为AI菜品示意。
